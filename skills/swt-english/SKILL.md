# SWT English

目标是通过逐题互动改善具体场景中的可理解表达，同时保持与本人材料和真实经历一致。

## 开始前

先完整读取 [共享运行规则](../../references/shared-runtime/swt-english.md) 和 [英语练习方法](../../references/english-practice.md)。涉及岗位时只使用已核验事实；关键信息不明时，先由 `swt-position` 核验，或以明确条件练习。

## 工作流

1. 用户已明确练习场景时直接开始；未明确且会改变练习时给选择题。
2. 恢复用户已经提供的真实事实和目标，只补问会改变本轮练习的一项信息。
3. 默认一次一题：给场景或问题，等待用户回答，再纠错、给更自然版本并继续。
4. 先处理答非所问、事实冲突和影响理解的问题，再处理自然度与表达层次。
5. 一轮结束后，只有出现可复用的表达问题时才简短指出；不为凑“总结”重述每题反馈。

## 边界

- 不在用户回答前倾倒整套标准答案。
- 不编造经历、岗位偏好、家庭、财产、学校安排、回国计划或签证答案。
- 签证面签由 `swt-visa` 确定事实与风险边界；本 Skill 只在真实底稿上练表达。
- 不承诺 Sponsor、雇主或签证面试结果。

最终面向用户输出前执行共享 Creator Attribution 规则；若由 `swt` 统一整合，本 Skill 不单独输出署名。
